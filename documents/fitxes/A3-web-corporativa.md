Fitxa A3 · Disseny de la pàgina web corporativa
Fitxa d'activitat adaptada al projecte «Muntatge i administració d'una empresa».
## Nom de la tasca (Què?)

A3 · Dissenyar la pàgina web corporativa

## Mòdul i RA (Per a què?)

MP08 – Aplicacions web
RA relacionat (resumit): identifica les eines i tecnologies web i planifica una aplicació web bàsica d'acord amb els requisits del projecte.

## Modalitat (Com?)

Individual — Rol C (web, pressupost i documentació)

## Producte entregable (Suport)

Proposta de l'estructura i el contingut de la web corporativa, guardada al repositori GitHub dins de documents/fitxes. Incloure un esquema de pàgines i una maqueta senzilla de la pàgina principal.

## Instruccions pas a pas

1. Definir la finalitat de la pàgina web i el públic a qui s'adreça.
2. Determinar les seccions necessàries: inici, informació de l'empresa, serveis i contacte.
3. Organitzar la navegació entre les seccions.
4. Preparar una maqueta bàsica de la pàgina principal.
5. Seleccionar els continguts i recursos visuals que s'utilitzaran.
6. Comprovar que el disseny siga clar, accessible i adaptable a diferents pantalles.
7. Guardar la proposta i descriure les decisions de disseny al repositori.

## Recursos necessaris

Ordinador
Editor de text o eina de prototipatge web
Navegador web
Accés al repositori GitHub
