# (Títol del projecte) — Muntatge i administracio d una empresa 
 
Crear una xarxa per a una empresa per facilitar la comunicacio i les trensferencies dins de la xarxa.
Per tant el que es farà es: Una xarxa local amb servidor, ordinadors i sistemes de seguretat. 

## Autor 
- Stilyan (smkmind) 
 
## Rols simulats 
- Rol A — (Insalacio de sistemes operatius i configuració del servidor) 
- Rol B — (Configuració de la xarxa i mesures de seguretat) 
- Rol C — (creacio de la pagina web, contar el pressupost i documentació del projecte) 
 
## Contingut del repositori 
- `documents/` — Document de Repte (Annex A) 
- `documents/fitxes/` — fitxes d'activitat (Annex B) 
- `configuracio/` — configuracions tècniques (quan s'execute el projecte)
